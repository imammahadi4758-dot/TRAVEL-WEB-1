# TravelGo — Explore Beautiful Bangladesh

A responsive, multi-page travel discovery website for Bangladesh.

## Files (all in one folder — no sub-folders)
- `index.html` — landing page, search and filters
- `destination.html` — destination details page
- `style.css` — styles
- `data.js` — all 31 destinations
- `app.js` — search, filters, sorting, navigation
- `bangladesh-travel-poster.png` — poster reference image

## Run locally
Open `index.html` in a browser (or use VS Code Live Server).

## Host free on GitHub Pages
Repo → Settings → Pages → Branch: `main`, Folder: `/ (root)` → Save.

## Notes
Google Fonts and destination photos load from the internet.
Always verify current weather, transport, permits and safety guidance before travelling.
